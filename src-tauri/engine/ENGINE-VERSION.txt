  session, so the hash should be compared with the upstream release notes
  before redistributing the installer.

Security
  The application never downloads or executes an inference binary at runtime.
  It only runs this bundled executable (or a binary explicitly placed by the
  operator under the app-data engine/ directory, or named by the
  MAILDFIR_LLAMA_SERVER environment variable). It binds to 127.0.0.1 and is
  started with a per-run random API key.
